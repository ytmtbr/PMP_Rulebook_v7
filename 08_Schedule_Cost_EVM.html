08 Schedule / Cost / EVM

Rule 1　Schedule Planning Flow

WBS / Work Packages ↓ Define Activities ↓ Sequence Activities ↓ Estimate Resources / Durations ↓ Develop Schedule ↓ Schedule Baseline ↓ Control Schedule
WBSの次にいきなりScheduleを作る。 Durationだけ先に考える。
Work Packages ↓ Activities ↓ Schedule

Rule 2　Critical Path

Network Paths ↓ Calculate Duration / Float ↓ Longest Path ↓ Critical Path ↓ Determines Project Duration

Critical Pathは通常、 Projectの最短完了期間を決める最長経路。

一番難しいActivity。 一番Costが高いActivity。 Activity数が一番多いPath。
Critical Path = Longest Duration Path

Rule 3　Total Float

Total Float = LS − ES = LF − EF

一般的なPMP計算問題では、 Critical PathのTotal Floatは0。

Critical Pathには必ず余裕がある。 Free FloatとTotal Floatを混同する。
Critical → Usually Zero Float

Rule 4　EVM基本4式

指標 式 意味
CV EV − AC Cost Variance
SV EV − PV Schedule Variance
CPI EV ÷ AC Cost Efficiency
SPI EV ÷ PV Schedule Efficiency
CV = AC − EV。 SPI = PV ÷ EV。 CPIとSPIを逆にする。
Cost → AC Schedule → PV Both compare with EV

Rule 5　CV / SVの読み方

CV > 0 → Under Budget CV < 0 → Over Budget SV > 0 → Ahead of Schedule SV < 0 → Behind Schedule
Varianceがマイナスだから良い。 CVとSVの意味を逆にする。
Positive = Good

Rule 6　CPI / SPIの読み方

CPI > 1 → Cost Efficient CPI < 1 → Cost Inefficient SPI > 1 → Ahead SPI < 1 → Behind

SPI = 0.6は 「60%完成した」という意味ではない。 予定に対するSchedule Efficiencyが0.6という意味。

SPI 0.6 = 60% Complete
Index > 1 Good < 1 Bad

Rule 7　EAC / ETC / VAC

EAC = Expected Total Cost ETC = Cost Needed to Finish VAC = BAC − EAC
Situation Typical Formula
Current cost performance continues EAC = BAC ÷ CPI
Past variance was exceptional EAC = AC + (BAC − EV)
Cost and schedule both affect remaining work EAC = AC + (BAC − EV) ÷ (CPI × SPI)
どのEAC問題でも同じFormulaを使う。
Read the Assumption Before Choosing EAC

Rule 8　Contingency vs Management Reserve

Reserve Purpose
Contingency Reserve Identified / Known Risks
Management Reserve Unforeseen Work within Project Scope / Unknown-unknowns
すべてのRiskをContingency Reserveで処理。 Management ReserveをCost Baselineに含める。
Known Risk → Contingency Unknown → Management Reserve

Rule 9　Reserve Analysis

Identified Risks ↓ Current Exposure ↓ Available Reserve ↓ Reserve Analysis ↓ Enough?

Reserve Analysisは、 現在のRisk Exposureに対して Contingency Reserve等が十分かを評価する。

Root Cause Analysisを選ぶ。 Sensitivity Analysisを選ぶ。 Probability × Impact Matrixを選ぶ。
Reserve Analysis = Is the Reserve Enough?

Rule 10　Sensitivity Analysisとの違い

Sensitivity Analysis ↓ Which Variable / Risk has the Greatest Impact?

Sensitivity Analysisは、 どのRiskやVariableがProject Outcomeへ 最も大きな影響を与えるかを見る。 Tornado Diagramが代表的。

「Contingency Fundingはいくら必要？」 でSensitivity Analysisを選ぶ。
Sensitivity = Biggest Driver Reserve Analysis = Enough Reserve?

Rule 11　Schedule Compression

Fast Tracking Crashing
ActivitiesをParallel化 Resourcesを追加
Risk ↑ Cost ↑
通常Sequentialな作業をOverlap Critical PathへResources投入
Fast Tracking = 人員追加。 Crashing = 並行作業。
Fast = Parallel Crash = Cost / Resources

Rule 12　CompressionはCritical Pathを見る

Need Shorter Schedule ↓ Identify Critical Path ↓ Evaluate Critical Activities ↓ Fast Track / Crash ↓ Recalculate Schedule

Non-critical Activityを短縮しても、 Project Completion Dateが短縮されないことがある。

適当なActivityへ人員追加。 最も遅れているActivityだけを見る。
Compress the Critical Path

Rule 13　Milestone

Important Event or Decision Point ↓ Zero Duration

Milestoneは重要な到達点を表し、 Durationは0。

Milestoneに作業期間を設定する。
Milestone = 0 Days

Rule 14　Burndown Chart

Remaining Work ↓ Compare with Ideal / Expected Line Actual Remaining > Expected Remaining ↓ Behind
線が高いほどProgressが良い。
Higher Remaining Work = Behind

Rule 15　Schedule / Cost Baseline変更

Need Baseline Change ↓ Impact Analysis ↓ Formal Change Request ↓ Approval ↓ Update Baseline ↓ Communicate / Implement
PM判断だけでBaseline変更。 実績が悪いからBaselineを実績に合わせる。 Sponsorの口頭指示だけで変更。
Bad Performance ≠ Reason to Rewrite Baseline

Rule 16　Forecast vs Baseline

Baseline = Approved Reference Actual Performance ↓ Analyze ↓ Forecast Future Outcome

Performanceが悪化した場合、 まずForecastを更新して将来を予測する。 Baselineは単なる最新予測ではない。

遅延したらBaselineを現在値へ変更する。
Baseline = Approved Target Forecast = Expected Outcome

Rule 17　Schedule / Cost Summary

Scope / WBS ↓ Activities ↓ Schedule + Cost ↓ Baseline ↓ Monitor Actual Performance ↓ EVM / Variance ↓ Forecast ↓ Corrective Action ↓ Formal Change if Needed

試験で迷ったら

  • Critical Path = Project Durationを決める最長経路
  • Critical Pathは通常Zero Float
  • CV = EV − AC
  • SV = EV − PV
  • CPI = EV ÷ AC
  • SPI = EV ÷ PV
  • Indexは1より大きければGood
  • VarianceはプラスならGood
  • Reserve Analysis = Reserveは十分か
  • Sensitivity Analysis = 最大Impact Driverは何か
  • Fast Tracking = Parallel
  • Crashing = Resources / Cost
  • Baseline変更にはFormal Approval
  • Performance悪化だけでBaselineを書き換えない
Formula ↓ Interpret ↓ Forecast ↓ Formal Change
