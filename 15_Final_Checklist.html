15 Final Checklist

Checklist 1　問題文を読んだ直後

□ 何が起きている？ □ Predictive / Agile / Hybrid？ □ Future Risk / Existing Issue / Change？ □ FIRST / NEXT / BEST のどれを聞かれている？ □ 問題文ですでに何が実施済み？ □ 情報は十分？それともAnalyzeが必要？
Context ↓ Classify ↓ Sequence

Checklist 2　選択肢を見る前の判断

□ 原因・Impactが不明 → Analyze □ 既に問題が発生 → Resolve / Correct □ 将来の不確実性 → Risk Response □ Baseline / Approved Planを変える → Formal Change Control □ People / Conflict → Coach / Facilitate □ External Environment → Monitor / Assess / Adapt
Choose the Process before the Answer

Checklist 3　FIRST / NEXT

□ このActionの前に必要なことはないか？ □ Analysisは既に済んでいないか？ □ Approvalは既に済んでいないか？ □ Issueは既に発生していないか？ □ 今選ぼうとしているのは最終Actionではないか？
最終的に必要 = FIRST ではない。
Right Action + Right Order

Checklist 4　Stakeholder

□ StakeholderをIdentifyしたか？ □ ExpectationsをGatherしたか？ □ Analyze / Prioritizeしたか？ □ Engagement Strategyが必要か？ □ Communication Planだけで解決しようとしていないか？
Identify ↓ Analyze ↓ Engage

Checklist 5　Scope / Requirements

□ Requirement Conflict → RTM □ Ownership / Work Package Detail → WBS Dictionary □ Project Boundary → Scope Statement □ Scope Baseline → Scope Statement + WBS + WBS Dictionary □ New Requirement → Impact Analysis + Change Control
何でもScope Statementを選ばない。
Requirement → RTM Work Package → WBS Dictionary

Checklist 6　Change / Governance

□ Impactを把握しているか？ □ Formal Change Requestが必要か？ □ Approval前に実装していないか？ □ Relevant Plan / Baselineを更新したか？ □ Approved Changeを実装したか？ □ 実装後にVerifyしたか？
Analyze ↓ Approve ↓ Update ↓ Implement ↓ Verify

Checklist 7　Risk / Issue

□ Future uncertainty → Risk □ Already happened → Issue □ Risk → Identify / Analyze / Respond / Monitor □ Issue → Analyze / Resolve / Track □ Register更新だけで終わっていないか？
Future → Risk Happened → Issue

Checklist 8　Quality

□ Known Defect → Correct / Retest □ Quality Change → Analyze / Change Control □ Process Compliance → Audit □ Deliverable Quality → Test / Inspect □ Acceptance Criteria / DoDを満たしているか？ □ CostやScheduleのためにQualityを勝手に下げていないか？
Build Quality ↓ Verify Quality ↓ Accept

Checklist 9　Agile / Hybrid

□ Valueを優先しているか？ □ Product OwnerとPriorityを確認したか？ □ Sprint Goalを守っているか？ □ Feedback Loopがあるか？ □ TeamをSelf-managingにしているか？ □ Sustainable Paceか？ □ HybridならGovernanceも維持しているか？
Agile = 何でも自由に変更。 Hybrid = Governance不要。
Value ↓ Feedback ↓ Adapt + Governance when required

Checklist 10　Team / Leadership

□ まず本人と話せないか？ □ Coachできないか？ □ Team全体ならFacilitateできないか？ □ PMが答えを与えすぎていないか？ □ TeamをEmpowerできないか？ □ Escalationは本当に必要か？
Direct Intervention Replacement Punishment Escalation を早く選ばない。
Coach ↓ Facilitate ↓ Empower ↓ Escalate Last

Checklist 11　Procurement

□ Formal Procurement Processを守っているか？ □ Fair / Transparent / Objectiveか？ □ PriceだけでVendorを選んでいないか？ □ ContractとPerformanceを比較したか？ □ Vendor Performanceを継続Monitorしているか？ □ Contract Changeを正式に処理したか？
Formal Fair Objective Monitored

Checklist 12　Business / External Environment

□ Business Objectiveは何か？ □ OutputではなくOutcome / Benefitを見ているか？ □ External EnvironmentをMonitorしているか？ □ PESTLEが適切ではないか？ □ Market ChangeにAdaptできるか？ □ Project単独ではなくStrategy / Programとの整合を見たか？
Objective ↓ Outcome ↓ Benefit ↓ Value

Checklist 13　Cost / Schedule

□ CV = EV − AC □ SV = EV − PV □ CPI = EV ÷ AC □ SPI = EV ÷ PV □ CPI < 1 → Over Budget □ SPI < 1 → Behind Schedule □ Critical Path → Longest Path / Usually Zero Float □ Fast Tracking → Parallel Work □ Crashing → Additional Resources / Cost □ Known Risk → Contingency Reserve
Cost → CPI / CV Schedule → SPI / SV

Checklist 14　Artifactを間違えていないか

Requirement Priority / Traceability → RTM Work Package Detail → WBS Dictionary Current Risk → Risk Register How to Manage Risk → Risk Management Plan Current Stakeholders → Stakeholder Register How to Engage → Stakeholder Engagement Plan Communication HOW → Communications Management Plan Overall Management HOW → Project Management Plan
Register = Current Information Plan = How to Manage

Checklist 15　危険な選択肢

□ Ignoreしていないか？ □ Assumeしていないか？ □ 問題文にない事実を作っていないか？ □ Blameしていないか？ □ Hideしていないか？ □ Formal Processを飛ばしていないか？ □ PMが一人で決めていないか？ □ Meetingだけで終わっていないか？ □ Document更新だけで終わっていないか？ □ SponsorにPMの仕事を投げていないか？ □ Escalationが早すぎないか？
No Shortcuts

Checklist 16　極端なAction

Immediately Replace Stop All Work Escalate Immediately Cancel Sprint Remove Team Member Ignore Requirement ↓ Does the situation truly justify this?

Safety・Legal・Compliance・Critical Qualityなどの 強い理由がなければ、極端なActionは慎重に判断する。

Extreme Action needs Extreme Context

Checklist 17　最後の2択になったら

Which option... □ 問題をより直接解決する？ □ Root Cause / Actual Needに近い？ □ 正しい順番になっている？ □ Collaborativeか？ □ Formal Processを守る？ □ Long-term Solutionになる？ □ PMのAuthority内でまず対応している？ □ Valueを守る？
Direct + Correct Sequence + PMI Mindset

Checklist 18　あなたのFull Examで要注意

① Scope Statementを選びすぎない → RequirementならRTM → Work PackageならWBS Dictionary ② Sponsorへ判断を投げない → PMがAnalyze / Facilitate / Manage ③ Meetingを万能解にしない → 問題を直接解決するActionを見る ④ Escalationを急がない → Current Levelで解決できるか確認 ⑤ Coachingより直接介入を選ばない → Individual ConflictならCoach ⑥ Price / Cost / Scheduleだけで判断しない → Quality / Risk / Value / Contractも見る ⑦ Baselineを勝手に変更しない → Formal Change Control ⑧ Document更新だけで終わらない → Action + Monitor ⑨ Business ObjectiveよりSolutionを先にしない → Objective → Value → Solution ⑩ AgileにPredictive Controlを持ち込まない → Value / Feedback / Self-management ⑪ 問題文にない前提を作らない → Given Facts Only ⑫ 正しいActionでも順番を間違えない → FIRST / NEXTを確認

Final 30-Second Check

1. What happened? ↓ 2. Risk / Issue / Change? ↓ 3. Predictive / Agile / Hybrid? ↓ 4. FIRST / NEXT? ↓ 5. Information sufficient? ↓ 6. Analyze needed? ↓ 7. Can PM / Team solve it? ↓ 8. Governance needed? ↓ 9. Which option directly solves the problem? ↓ 10. Verify / Monitor afterward?
Context ↓ Classify ↓ Analyze if Needed ↓ Act ↓ Verify

Final Golden Rules

Do not assume. Do not bypass process. Do not escalate too early. Do not confuse documentation with action. Do not optimize only cost or schedule. Do not implement unapproved changes.
Understand ↓ Classify ↓ Analyze if Needed ↓ Collaborate ↓ Follow Appropriate Process ↓ Act ↓ Verify ↓ Improve

PMPでは「もっともらしいAction」ではなく、 Contextに対して「正しい順番で、最も直接的に問題を解決するAction」を選ぶ。
