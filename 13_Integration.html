Rule 1　Project Integration Management

Business Need ↓ Project Charter ↓ Project Management Plan ↓ Direct & Manage Work ↓ Monitor & Control ↓ Integrated Change Control ↓ Close Project
各Knowledge Areaを独立して考える。
Integration connects everything.

Rule 2　Project Charter

Business Case ↓ Sponsor Approval ↓ Project Charter ↓ Project Authorization
PMがProjectを開始する。
Sponsor authorizes the project.

Rule 3　Project Management Plan

Integrates Scope Schedule Cost Quality Resources Communication Risk Procurement Stakeholders
単なるスケジュールだと思う。
The PMP Plan integrates every subsidiary plan.

Rule 4　Project Management Plan vs Documents

Plan Documents
How to manage Current project information
Management approach Status / Register / Log
Baseline included Updated frequently
Risk RegisterをPlanと思う。
Plan = HOW Documents = WHAT

Rule 5　Direct and Manage Project Work

Approved Plan ↓ Execute Work ↓ Produce Deliverables ↓ Collect Work Performance Data
Monitoringを先に行う。
Execute before Control.

Rule 6　Monitor and Control

Compare Actual vs Baseline ↓ Variance ↓ Corrective Action
問題が出るまで何もしない。
Compare Actual with Plan.

Rule 7　Integrated Change Control

Change Request ↓ Impact Analysis ↓ Approve / Reject ↓ Update Baselines ↓ Implement
Scopeだけ見る。
Integration considers every knowledge area.

Rule 8　Work Performance Data / Information / Reports

Type Meaning
Data Raw observations
Information Analyzed data
Reports Presented information
DataとInformationを混同する。
Data ↓ Information ↓ Report

Rule 9　Lessons Learned

Capture ↓ Share ↓ Reuse ↓ Improve Future Projects
Project終了時だけ作る。 犯人探しをする。
Lessons Learned is continuous.

Rule 10　Project Closing

Verify Acceptance ↓ Close Contracts ↓ Archive Documents ↓ Lessons Learned ↓ Release Resources
成果物完成だけで終了。
Close everything, not only delivery.

Rule 11　Integration Thinking

Every major decision ↓ Check Scope Schedule Cost Quality Risk Resources Stakeholders Business Value
1つのKnowledge Areaだけ最適化する。
Optimize the whole project, not one area.

Rule 12　Integration Summary

Charter ↓ Project Management Plan ↓ Execute ↓ Monitor ↓ Integrated Change ↓ Close

あなたのFull Examで多かったミス

  • Impact Analysisを飛ばす
  • Project DocumentsとManagement Planを混同する
  • Data / Information / Reportを混同する
  • Lessons Learnedを最後だけと思う
  • Integration視点ではなく個別最適で考える
Integration問題は Whole Project Impact Analysis Project Management Plan この3つを最優先。
